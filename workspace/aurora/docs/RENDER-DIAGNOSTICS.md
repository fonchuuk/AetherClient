# Первый этап диагностики рендера

## Подтверждено чтением исходников

В WorldRenderDispatcher был один общий счётчик failures для обновления кадра,
частиц и блоков. Успешный кадр его не сбрасывал. При 12 накопленных ошибках
отключались оба прохода рендера, хотя сообщение говорило об ошибках подряд.
Стек записывался только для первых трёх ошибок на все проходы вместе.
Это дефект обработки ошибок, а не доказанная причина пользовательского вылета.

## Изменения

- Отдельные RenderFailureTracker для frame, particles и blocks.
- Успешный вызов сбрасывает счётчик последовательных ошибок своего прохода.
- Первые три ошибки и двенадцатая записываются с полным стеком, идентификатором
  модуля/прохода, этапом и счётчиком. Отключение явно записывается в лог.
- Получение буфера и начальная работа со стеком матриц перенесены внутрь try.
- Ошибка выделения буфера частиц теперь учитывается предохранителем вместо
  бесконечного возврата без ограничения попыток.
- Добавлены три JUnit-теста: порог отключения, сброс после успеха, независимость
  проходов. Тесты не запускались.
- Одинаковые изменения внесены в обе отслеживаемые копии исходников:
  aurora/client и workspace/aurora/client.

## Проверки в этой среде

`git diff --check` — код возврата 0, вывода нет.

`java -version`, `javac -version`, `go version` — команды не найдены.

Из workspace/aurora:

```
sh ./gradlew --configure-on-demand :client:compileJava :client:test --console=plain --no-daemon
```

Код возврата 1:

```
ERROR: JAVA_HOME is not set and no 'java' command could be found in your PATH.
```

Компиляция не состоялась. Minecraft и Windows-лаунчер не запускались.
Новый jar/exe не собран, существующие бинарники не менялись, релиз не публиковался.
Визуальная часть меню и галереи не проверялась. Аудит всех модулей не завершён.

## Что нужно для продолжения

Файл ~/.aetherglass/logs/latest.log (либо latest.txt, если так называется)
и, если существует, ~/.aetherglass/crash-reports/crash-*.txt от неудачного запуска.
Перед отправкой можно скрыть персональные имена/пути и адреса серверов;
сохраните полный стек исключения и список модов.

Имеющийся tools/rebuild.sh нельзя считать готовым для этой среды: в нём
жёстко задан cd /home/user/aurora, не совпадающий с текущим checkout,
и загрузки инструментов с доменов за пределами разрешённого списка.
