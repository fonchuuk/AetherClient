# Очистка текущего дерева и исправления по коду

## Приватность

Из Git убраны (локальные копии сохранены): uploads/, workspace/uploads/,
backup/, workspace/backup/ и workspace/.config/ (16 файлов).
Архивы не публикуются, так как могут сохранять старые файлы и данные окружения.
Добавлены ignore-правила для этих каталогов, локальных auth/config JSON и .env.
scripts/privacy_audit.py проверяет отслеживаемые пути и стандартные сигнатуры
GitHub-токенов и приватных ключей, не выводя значения находок.
Проверка не доказывает отсутствие любых персональных данных.

История Git не переписывалась. Старые коммиты и ветка master до слияния
содержат исходные файлы. Ранее раскрытый в чате токен необходимо отозвать;
удаление файлов и новые коммиты не заменяют отзыв секрета.
Публичный GitHub-логин в URL проекта оставлен: он нужен для обновлений.
Тестовые фикстуры и тесты не удалялись.

## Подтверждённые дефекты исходников

1. ModuleManager.shutdown() выключал модули до saveNow(), записывая их
   выключенными на следующий запуск. Теперь сохранение идёт первым,
   освобождение ресурсов — в finally даже при ошибке сохранения.
2. WorldRenderDispatcher вычитал позицию камеры матрицей, хотя ParticleSystem
   и BlockEffectRenderer уже передавали camera-relative координаты.
   Убрано повторное смещение. В частицах double преобразуется во float
   после вычитания, чтобы не терять точность далеко от начала координат.
3. Частицы, блоки и геометрия рук используют entityTranslucent, но вершины
   не заполняли overlay/normal, а ShapeBuffer — также light. Добавлена
   запись всех атрибутов NEW_ENTITY, нормаль граней рассчитывается.
4. RenderResources.acquire() обнулял builder при ошибке immediate(),
   не закрывая уже выделенный native-буфер. Теперь выполняется release().

Добавлены регрессионные тесты порядка shutdown (включая сбой сохранения)
и наличия всех атрибутов вершин частиц/геометрии блоков и рук.
Проверки вершин используют записывающий VertexConsumer, не GPU.
Эти исправления не являются подтверждением причины пользовательского вылета.

Сборка и тесты выполняются Windows CI; фактический запуск Minecraft,
окна лаунчера и визуальная проверка в эту проверку не входят.
