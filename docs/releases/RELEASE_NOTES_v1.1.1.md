# AetherGlass v1.1.1 — RSHIFT-меню, объёмные частицы, чистое небо

Правки по списку замечаний к v1.1.0. Всё перечисленное проверено на запущенной
игре (скриншоты — `screenshots/04…07`), а не «по коду».

## 1. Анимация меню RSHIFT

- **Открытие — `easeOutCubic` 0,18 с**, закрытие — **`easeInCubic` 0,15 с**.
  Раньше обе фазы шли одной экспоненциальной кривой `easeOutCubic`, только с
  разной скоростью, поэтому закрытие читалось как «залипание».
- Раскрытие считается по реальному времени кадра (`openT += dt / duration`),
  а не сходимостью `1 - exp(-k·dt)`: длительность теперь ровная и не зависит
  от FPS. Задержка в 1 с отсутствует — меню схлопывается в тот же кадр, где
  нажали Escape/RSHIFT, и через 120 мс на экране уже нет панелей
  (`screenshots/07_menu_close_120ms.png`).

## 2. Визуал панелей

- **Blur действительно заработал.** Миксин `GuiMixin`, который снимает
  уменьшенный кадр для `BackdropBlur`, не был прописан в
  `aetherglass.mixins.json` — код размытия существовал, но не вызывался ни
  разу, и панели падали в режим «полупрозрачная заливка». Теперь миксин
  зарегистрирован.
- Размытие усилено (уменьшение кадра 1/8 → 1/14) и стало дешевле: середина
  панели рисуется **одним** блитом, построчно идут только полосы скруглений
  (было — по строке на всю высоту панели).
- **Светлая кромка** сверху и слева у каждой карточки: панель читается как
  выпуклая стеклянная пластина.
- **Диагональный блик** и тонировка стекла сохранены, тонировка чуть легче
  (мир под панелью видно лучше).
- Панель столбика (`drawLiquidGlassPanel`) раньше была глухой заливкой
  `#08090D` на 236/255 — теперь идёт тем же стеклянным путём, что и карточки.
- Углы — те же 9-slice/SDF-текстуры с врезкой по таблице `CORNER_INSET`,
  поэтому скругления гладкие.

## 3. Верхняя панель вкладок (HUD, «Блоки / Руки / Частицы / …»)

- Кнопки стали шире, внутренние отступы 8 px вместо 5 px, зазор 5 px.
- **Ширина подбирается под экран**: три набора отступов (8/6/4 px), берётся
  первый, который влезает; плюс страховочный сдвиг. Раньше на узком окне
  вкладка «Экран» просто обрезалась за краем.
- **Неон только у активной вкладки**: подложка + акцентная полоса снизу +
  светлая кромка сверху. Неактивные — без подсветки вообще.
- **HUD больше не рисуется под открытым меню RSHIFT** — раньше верхняя панель
  вкладок просвечивала сквозь панели меню и они накладывались друг на друга.

## 4. Частицы — настоящая 3D-геометрия

- Новый `ParticleMesh`: сфера (5×3 квада), куб (6 граней), кольцо (6 сегментов).
  Вершины и нормали предвычислены один раз, в кадре — только масштаб, поворот
  (свой yaw/tilt у каждой частицы) и раскраска.
- Освещение по нормалям: **ламбертово затенение + мягкий rim** по боку, плюс
  пульсация. Плоских билбордов, развёрнутых к камере, больше нет — билборд-код
  удалён.
- Радиус увеличен (0,55 → 0,82 от `size`): на дистанции частица не сжимается
  в точку.
- Соответствие форм: «Кольца» → кольцо, «Снежинки/Звёзды» → гранёный кристалл,
  «Сферы/Искры/Сердца» → сфера.

## 5. Небо

- **Кислотных полос больше нет**: панорамы `sky_video_*.png` перерисованы
  генератором `tools/gen_sky_video.py` — гладкие градиентные развёртки без
  «занавесов».
- **Ванильных облаков нет вообще**: `CloudRendererMixin` отменяет проход
  облаков и по тумблеру, и всегда, когда активен видео-купол. Чёрные ромбы на
  скриншоте были именно ими.
- Купол — равноугольная развёртка видео-листа (12 кадров 512×192), кадр
  выбирается по времени, купол вращается. Если текстура не загрузилась,
  остаётся тёмно-синяя подложка (`blendSky`), без артефактов.

## 6. Прочее

- Версия поднята: `mod_version` 1.0.8 → **1.1.1** (в UI и логе было 1.0.8 при
  релизе v1.1.0), теперь в меню и лаунчере честная версия из константы.
- `AlwaysPreTouch` больше не добавляется при `-Xmx < 1024M`: на машинах с
  небольшим объёмом памяти JVM убивалась OOM ещё до главного меню (поймано на
  стенде).
