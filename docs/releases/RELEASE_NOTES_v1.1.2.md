# AetherGlass v1.1.2 — вкладка «Помощник» (AI-разбор крашей + FAQ)

Новая вкладка в лаунчере: одна большая кнопка AI-диагностики и весь FAQ сразу
на экране, без аккордеонов. Скриншот — `screenshots/08_assistant_tab.png`.

## 1. AI-разбор краша

- **Кнопка «Проверить последний краш-репорт и выявить причину»** — большая,
  акцентная, во всю ширину панели.
- Лаунчер сам находит самый свежий источник сбоя: сначала
  `<gameDir>/crash-reports/*.txt` (новейший по времени), иначе
  `<gameDir>/logs/latest.log` и выжимку вокруг строк `ERROR`/`Exception`.
  Показывается, какой именно файл проверен и когда он изменён.
- **Никаких полей для API-ключа.** По умолчанию используется открытый
  OpenAI-совместимый шлюз `text.pollinations.ai` — он работает без ключа.
  Свой адрес/ключ/модель можно задать переменными окружения
  `AETHERGLASS_AI_URL`, `AETHERGLASS_AI_KEY`, `AETHERGLASS_AI_MODEL`.
- В модель уходит только выжимка до 7000 символов: описание краша, последний
  `Caused by`, стек и список имён модов. Полные логи не отправляются.
- **Офлайн-режим.** Если сети нет, шлюз ответил ошибкой или таймаут — показывается
  локальный разбор по правилам (`CrashAssistant.localDiagnosis`): OOM, версия Java,
  конфликт модов/Mixin, отсутствующая зависимость, сбой графики, битый `.jar`.
  Ответ есть всегда, меняется только подпись источника.
- Запрос идёт в фоновом потоке (`SwingWorker`), окно не подвисает.

## 2. FAQ — без аккордеонов

Восемь вопросов и ответов видны сразу, каждый в стеклянной карточке:
вопрос — жирным, ответ — мелким шрифтом, перенос по фактической ширине карточки.

1. Сколько памяти выделить сборке?
2. Где найти лог запуска и краш-репорты?
3. OptiFine или Sodium?
4. Почему вылетает игра с моей сборкой?
5. Какой загрузчик выбрать — Fabric, Forge или NeoForge?
6. Как обновить моды без потери мира?
7. Почему лагает, хотя FPS высокий?
8. Как перенести сборку на другой компьютер?

## 3. Визуал

Всё в текущем Liquid Glass-стиле лаунчера: матовые стеклянные карточки со
скруглением 9 px, неоновая точка у вопроса, подсветка при наведении, блок
заключения с пульсирующей обводкой и чипом источника («нейросеть» / «локальный
разбор»).

## Технические детали

- Новый класс `core/CrashAssistant` — поиск отчёта, выжимка, запрос к модели,
  локальные правила, очистка markdown из ответа.
- `UiKit.faqCard(...)` — карточка «вопрос — ответ»; `UiKit.WrappingText` —
  текст с переносом, который не раздувает ширину ленты (иначе появлялась
  горизонтальная прокрутка).
- `UiPreview` теперь умеет снимать вкладку «Помощник» с реальным прогоном:
  стенд кладёт тестовый crash-report и моды, вызывает анализ и рендерит PNG.
