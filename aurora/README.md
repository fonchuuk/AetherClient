# AetherGlass Client

Minecraft-клиент с собственным лаунчером для **Minecraft Java Edition 1.21.11**
на **Fabric Loader 0.19.5**.

Это рабочий проект, а не макет: клиент собирается Gradle, лаунчер — Go,
логика лаунчера покрыта 29 тестами.

| Модуль | Что это | Результат сборки |
|--------|---------|------------------|
| `client` | мод Fabric: своё главное меню, 8 модулей, визуальные эффекты, HUD, конфиг | `AetherGlass.jar` (240 КБ, ремаплен в intermediary) |
| `launcher-go` | лаунчер: вход через Microsoft, установка игры и модов, запуск, своя Java | `AetherGlass-Launcher.exe` (8.5 МБ, настоящий Windows `.exe`, без Java) |
| `installer` | установщик: ярлыки, запись в «Программы и компоненты» | не входит в поставку: по требованию нужен был только сам лаунчер |

## Установка за минуту

1. Взять `AetherGlass-Launcher.exe`.
2. Запустить — установщик не нужен, Java тоже не нужна.
3. В лаунчере войти в аккаунт Microsoft → «Игра» → «Установить» → «Играть».

Лаунчер сам поставит Minecraft 1.21.11, Fabric Loader 0.19.5, Java 21 от Mojang,
Fabric API, 10 модов оптимизации и мод клиента.

Подробный отчёт о том, что сделано, а что нет: `docs/RELEASE.md`.

**Все эффекты написаны вручную** через Minecraft rendering API и Fabric:
без Iris, без OptiFine, без шейдерных пакетов и без шейдерных модов —
ни одной строчки GLSL.

## Что внутри

### Свой главный экран
Ванильное меню заменено полностью. Слева — крупная стеклянная панель с
названием, справа — док навигации: **Одиночная игра**, **Сетевая игра**,
**Realms**, **Настройки**, **Язык**, **Доступность**, **Функции клиента**,
**Экранные элементы**, **О клиенте**, **Выход** (с подтверждением). Каждая
кнопка открывает настоящий экран игры.

Фон — зимняя ночь: холодный градиент, сияние над горизонтом, ореол луны,
редкие стеклянные пластины и медленный снегопад. Поверх всплывают
атмосферные надписи: одиннадцать заданных фраз дрейфуют, плавно гаснут,
чуть реагируют на курсор и никогда не заходят на панели и кнопки. Настроек
включения, количества и прозрачности у них нет — так и задумано.

Три страницы (**Главная / Функции / Настройки**) сделаны в одном стиле
«жидкое стекло» (многослойная панель с бликом, окантовкой и свечением),
отклик-рябь на нажатие, адаптация под разрешение и масштаб GUI.
Анимации считаются от времени, поэтому одинаково выглядят при любой частоте кадров.

### Восемь модулей, у каждого свои настройки
Оформление · Частицы · Эффекты блоков · Эффекты рук · Эффекты неба ·
Радуга · Прицел · Экранный интерфейс.

### Эффекты, которые рисуются в мире
- **Частицы** — 6 форм (круг, квадрат, звезда, кольцо, сердце, искра), текстуры
  сгенерированы скриптом, плавный переход цвета, пул без аллокаций в цикле, предел 1 500.
- **Блоки** — контур по настоящей `VoxelShape` блока (плита, ступенька, факел — правильно),
  пульсация, частицы при ударе и вокруг руд/хранилищ/света/растений.
- **Руки** — оверлей **поверх** нарисованной ванильной модели (не вместо неё),
  4 стиля, анимация появления и размаха.
- **Небо** — изменение цветов состояния рендера неба, 5 пресетов, свои два цвета.
- **Радуга** — **один общий контроллер цвета** на все эффекты, а не пять отдельных механизмов.

### HUD из 15 элементов
Логотип, fps, производительность, координаты, направление, время, биом,
время в мире, эффекты, цель, предмет в руке, снаряжение, стрелы, нажатия клавиш,
CPS. Всё перетаскивается мышью в редакторе; позиции хранятся в долях экрана,
поэтому не «уезжают» при смене разрешения.

### Лаунчер
Вкладки **Игра / Моды / Настройки / Логи**. Установка клиента, библиотек,
ресурсов, Fabric Loader и модов с прогрессом и отменой, объём памяти, путь к Java
с проверкой версии, защита от повторного запуска, понятные сообщения об ошибках.
Скачиваются только файлы из официального манифеста Mojang и с Modrinth
по контрольным суммам SHA-512 из нашего манифеста.

### Вход в аккаунт
Настоящий поток Microsoft → Xbox Live → XSTS → Minecraft. Пароль не вводится
и не хранится. Требуется свой идентификатор приложения Azure — см.
[«Известные ограничения»](docs/LIMITATIONS.md).

## Требования

| Компонент | Версия | Откуда взято и чем проверено |
|-----------|--------|------------------------------|
| Minecraft Java Edition | **1.21.11** | `piston-meta.mojang.com/mc/game/version_manifest_v2.json` (реальный запрос, HTTP 200) |
| Fabric Loader | **0.19.5** | `meta.fabricmc.net/v2/versions/loader` |
| Fabric API | **0.141.6+1.21.11** | Modrinth API, фильтр по `game_versions=["1.21.11"]`, `loaders=["fabric"]` |
| Java для игры | **21+** | поле `javaVersion.majorVersion` в JSON версии 1.21.11 |
| Java для сборки | Temurin 21.0.12.1 | проверено сборкой |
| Gradle | 9.7.1 (обёртка `gradlew`) | дистрибутив `gradle-9.7.1-bin.zip` |
| Fabric Loom | 1.17.21 | `maven.fabricmc.net` (версия под JVM 21) |
| Маппинги | `loom.officialMojangMappings()` | Yarn для 1.21.11 отсутствует: `meta.fabricmc.net/v2/versions/mappings/1.21.11` → `Not Found` |

Дополнительно нужно: **не меньше 2 ГБ свободной памяти** для задачи `remapJar`
и интернет при первом запуске лаунчера (скачивание игры и модов).

## Быстрый старт

Клиент (мод):

```bash
export JAVA_HOME=/путь/к/jdk-21        # для сборки нужна Java 21
./gradlew build                        # клиент с ремапом + тесты
```

Лаунчер:

```bash
cd launcher-go && ./build.sh           # → ../AetherGlass-Launcher.exe
```

В лаунчере: вкладка **«Аккаунт»** → **«Войти через Microsoft»** → вкладка
**«Игра»** → **«Играть»**. Java подхватится сама; свою можно указать на
вкладке **«Java»**.

Лаунчер сам скачает Minecraft 1.21.11, библиотеки, ресурсы, Fabric Loader,
Fabric API, 10 оптимизационных модов и установит собранный мод клиента
в каталог `mods` игры.

## Почему лаунчер — это один .exe, и Java ему не нужна

Лаунчер написан на Go и собирается в обычный файл Windows:

```
AetherGlass-Launcher.exe   8.5 МБ, PE32+ (GUI), x86-64
```

- **Java не нужна, чтобы запустить лаунчер.** Внутри нет ни jar, ни байткода:
  Go-код компилируется в машинный. Никакого «установите Java 21, чтобы
  поиграть» — этот exe открывается на чистой Windows.
- **Java нужна самой игре**, и лаунчер ставит её сам: качает официальный
  рантайм Mojang (`java-runtime-delta`, Java 21) в каталог игры. Можно указать
  свою `javaw.exe` на вкладке «Java» — лаунчер проверит версию.
- **Никакого установщика.** Запустил exe — увидел окно.
- **Стекло считает видеокарта**: окно渲染ит движок Chromium, поэтому
  размытие подложки и преломление бесплатны для процессора.

Собрать самому (нужен Go 1.21+, работает и из Linux — кросс-компиляция):

```bash
cd launcher-go
./build.sh          # тесты → проверка кода → иконка → AetherGlass-Launcher.exe
```

Скрипт сам ставит `rsrc` для иконки, собирает без cgo и кладёт готовый файл
в корень репозитория. Проверка логики отдельно: `go test ./core` (29 тестов).

## Как это устроено

```
launcher  ──▶ скачивает и запускает игру (вход, файлы, аргументы JVM)
client    ──▶ мод: меню, модули, эффекты, конфигурация
```

Зависимости внутри клиента направлены строго в одну сторону, циклов нет:

```
gui  ──▶  modules  ──▶  render  ──▶  utils
  │          │            │
  └──────────┴────────────┴──────▶  config
```

| Пакет | Отвечает за |
|-------|-------------|
| `gui` | экраны, собственные виджеты, тема, примитивы рисования |
| `modules` | модули, их настройки, включение/выключение |
| `render` | эффекты, единственный контроллер цвета, пул частиц, общий буфер вершин |
| `config` | один JSON в своём каталоге, восстановление при повреждении |
| `optimization` | отчёт о установленных оптимизационных модах |
| `utils` | логирование |
| `launcher-go/core` | установка, запуск, вход, моды, Java — вся логика, без интерфейса |
| `launcher-go/uiweb` | окно и «жидкое стекло»: Chromium (WebView2) плюс страница `webui/index.html` |

**Объём кода:** клиент — 64 файла, ~7 300 строк, самый крупный класс — 366 строк
(`HudPainter`); лаунчер — Go, ~4 700 строк, из них логика `core` покрыта
29 тестами. Файлов «на тысячи строк» нет.

**Вмешательство в игру минимально: ровно 3 миксина**, каждый — в метод,
проверенный по байткоду игры (`javap`):

| Миксин | Куда | Зачем |
|--------|------|-------|
| `MinecraftMixin` | `Minecraft.setScreen` | подмена стандартного главного меню |
| `ItemInHandRendererMixin` | `ItemInHandRenderer.renderHandsWithItems` | эффекты рук поверх ванильной модели |
| `SkyRendererMixin` | `SkyRenderer.extractRenderState` | изменение цвета неба в мире |

Подробности — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Как выглядит лаунчер

Один `.exe`, внутри — движок Chromium (WebView2, входит в Windows 10 и 11).
Интерфейс — обычная страница (`launcher-go/uiweb/webui/index.html`), поэтому
стекло настоящее, а не нарисованное:

| Слой | Чем сделан | Что даёт |
|------|-----------|----------|
| Размытие подложки | `backdrop-filter: blur() saturate() brightness()` | фон под панелью размывается и подсвечивается, как под линзой |
| Преломление | SVG `feDisplacementMap` по `feTurbulence` | пиксели фона у кромки **сдвигаются**, а не просто мылятся — тот самый «загиб» стекла |
| Полупрозрачная заливка | градиент `rgba(150,172,255,.18)` → `rgba(70,96,190,.10)` | стекло пропускает фон |
| Кромка | `inset 0 1px 0 rgba(255,255,255,.42)` + рамка | тонкая светлая линия по верхнему краю |
| Глубина | три тени: внутренняя, внешняя 60 px, свечение | панель висит над фоном |

Размытие и преломление считает видеокарта — процессор не нагружен, поэтому
фон может медленно плыть (пятна анимируются `transform`). Палитра одна с
клиентом: глубокий синий, фиолетово-бирюзовое свечение. Пружинистая анимация
(`cubic-bezier(.34,1.56,.64,1)`) на кнопках, переключателе и смене вкладок.

Снимков в репозитории нет: проверить вид по-настоящему можно только запуском
на Windows.

## Проверка

```
./gradlew build              → BUILD SUCCESSFUL
./gradlew :client:test       → 9 тестов, 0 провалов
./gradlew :launcher:test     → 12 тестов, 0 провалов
```

```
./gradlew build              → BUILD SUCCESSFUL (с нуля: 17 задач, 2 мин 14 с)
./gradlew :client:test       → 11 тестов, 0 провалов
./gradlew :launcher:test     → 14 тестов, 0 провалов
python3 tools/verify_mods.py → 10 модов сверены с живым API Modrinth
запуск игры под Xvfb (llvmpipe, OpenGL 4.5):
    Loading 91 mods → [Aurora] AetherGlass Client готов: Minecraft 1.21.11, загрузчик 0.19.5
```

Проверено по-настоящему: версии 1.21.11 / Fabric Loader / Fabric API существуют
(запросы к официальным API), Java-версия взята из манифеста игры,
сигнатуры методов сверены по байткоду игры и исходникам Fabric API,
миксины после сборки содержат intermediary-имена.

**Игра запускалась по-настоящему** — не в теории: лаунчер поставил Minecraft,
70 библиотек, ресурсы и моды, собрал командную строку, и Fabric Loader поднял
91 мод, в том числе `aetherglass`. Настоящий журнал — в
[`docs/VERIFICATION_LOG.md`](docs/VERIFICATION_LOG.md).
Именно этот прогон нашёл баг, из-за которого игра вообще не стартовала
(не устанавливался Fabric API) — он исправлен и закрыт тестами.

Что **не** проверено и почему — честно перечислено в
[`docs/LIMITATIONS.md`](docs/LIMITATIONS.md): до титульного экрана игра
в песочнице не доходит — программный OpenGL на двух ядрах встаёт на
текстурных атласах. Контрольный прогон **без** десяти оптимизаций (только
Fabric API и наш клиент) встаёт там же и показывает ту же картинку — значит,
дело в окружении, а не в клиенте. Но факт есть факт: **меню глазами пока
никто не видел**.
