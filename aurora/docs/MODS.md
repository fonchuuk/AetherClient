## Устанавливается одиннадцатым файлом: Fabric API

Fabric API **не входит** в десятку оптимизаций, но ставится обязательно и
проверяется как зависимость. Почему это важно, выяснилось на реальном запуске:
мод `EntityCulling` поставляет внутри себя библиотеку `TRender`, а она требует
Fabric API. Без неё Fabric Loader вообще не запускает игру:

```
Mod 'TRender' (trender) 1.0.17 requires any version of fabric-api, which is missing!
```

Поэтому в каталоге `mods` оказывается **одиннадцать файлов**: десять
оптимизационных модов плюс Fabric API. Это проверяется отдельным тестом
(`modInstallerInstallsFabricApiTogetherWithTenMods`).

## Обязательная библиотека (не считается оптимизацией)

| Мод | Версия | Назначение |
|-----|--------|------------|
| Fabric API 0.141.6+1.21.11 | `0.141.6+1.21.11` | Библиотека API Fabric (доступ к событиям и реестрам игры). Обязательна для части модов, в список из 10 оптимизаций не входит |

Требуется модам: `entityculling`, `dynamic-fps` (проверено по полю `dependencies`
в ответе API Modrinth и подтверждено запуском игры).

Зависимости записаны в манифесте слагами, а не внутренними идентификаторами,
и проверяются до скачивания: если мод требует проект, которого нет в манифесте,
лаунчер скажет об этом сразу и назовёт, чего именно не хватает.

## Где заданы точные ссылки и контрольные суммы

`launcher/src/main/resources/mods.json` — машиночитаемый манифест. Для каждого мода там есть
имя файла, URL на `cdn.modrinth.com`, размер, SHA-1 и SHA-512. Лаунчер скачивает файл только
если его нет или контрольная сумма не совпадает, а после загрузки проверяет SHA-512.

## Проверка совместимости и конфликтов

- Каждый мод проверен на наличие сборки под `game_versions = ["1.21.11"]` и `loaders = ["fabric"]`.
- Пересечение функций исключено по ролям: рендер чанков (Sodium), игровая логика (Lithium),
  сеть (Krypton), память (FerriteCore), генерация и загрузка чанков (C2ME),
  отсечение сущностей (EntityCulling),Immediate mode рендер (ImmediatelyFast),
  свет (ScalableLux), JVM-оптимизации (BadOptimizations), экономия ресурсов в фоне (Dynamic FPS) — по одному моду на роль.
- Шейдерных модов (Iris, OptiFine) в списке нет: они запрещены условием задачи,
  Sodium используется без шейдерной поддержки.
- Моды, у которых нет сборки под 1.21.11 для Fabric (Starlight, Memory Leak Fix, Noisium,
  SmoothBoot, DashLoader, ModernFix, CullLessLeaves, EMI, Enhanced Block Entities),
  в список не включены — это проверено запросами к API.

## Отказ от вымысла

Ссылки, версии и размеры взяты из ответов API Modrinth, полученных при подготовке проекта.
При появлении новых версий манифест обновляется теми же запросами; лаунчер не подбирает
версии автоматически, чтобы установка оставалась воспроизводимой.
