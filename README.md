# AetherGlass

Клиентский мод для **Minecraft Java 1.21.11 (Fabric)** и лаунчер к нему.
Своё главное меню в стиле «жидкого стекла», атмосферные надписи, эффекты
рук, блоков, неба и частиц — всё нарисовано кодом, **без шейдерных паков,
без Iris и OptiFine, без читов**.

---

## Что скачать

Все файлы одного выпуска лежат в **[Релизах GitHub](../../releases)**:

| Файл | Что это | Размер |
|---|---|---|
| `AetherGlass-Setup.exe` | установщик: ставит лаунчер, создаёт ярлыки, умеет обновлять и удалять | 2.05 МБ |
| `AetherGlassLauncher.exe` + `AetherGlassLauncher.jar` | лаунчер (exe ищет jar рядом с собой) | 0.13 + 0.14 МБ |
| `AetherGlass.jar` | сам мод — лаунчер кладёт его в игру сам | 1.68 МБ |
| `AetherGlass-Launcher.exe` | нативный лаунчер одним файлом: Java для него не нужна, мод уже внутри | 9.68 МБ |
| `CHECKSUMS.txt` | суммы SHA-256 | — |

Два лаунчера — это не дубли, а разные ответы на разное:

- **`AetherGlass-Setup.exe` → `AetherGlassLauncher.exe`** — тот путь, который
  просили в задаче: настоящий установщик с ярлыками и записью в «Программы
  и компоненты». Нужна Java 21 (лаунчер скачивает рантайм Mojang сам).
- **`AetherGlass-Launcher.exe`** — один файл без установки и без Java.
  Мод вшит внутрь, поэтому он такой большой.

Проверить, что файл дошёл целым: `sha256sum -c CHECKSUMS.txt`.

Ни один `.exe` не является переименованным `.jar`: jar оборачивает launch4j
(компиляция ресурсов через `windres`, линковка через `ld`), а нативный
лаунчер собирается компилятором Go. Это проверяется разбором заголовков PE —
`python3 scripts/check_pe.py <файлы>`.

## Как пользоваться

1. Запустить `AetherGlass-Setup.exe` (или сразу `AetherGlass-Launcher.exe`).
2. Вкладка «Аккаунт» — один из двух способов:
   - **«Войти через Microsoft»** — откроется браузер, пароль вводится на сайте
     Microsoft; лаунчер его не видит и не хранит. Даёт доступ к серверам и Realms;
   - **«Играть офлайн»** — вписал имя и играешь. Без входа в Microsoft.
3. Вкладка «Игра» → «Установить / обновить», потом «Играть».
4. Java ставить самому **не нужно**: лаунчер скачивает официальный рантайм
   Mojang (Java 21) в каталог игры. Хочется свою — вкладка «Java».

Каталог игры по умолчанию: `C:\Users\<тебя>\.aetherglass`. Там же настройки
(`aurora-launcher.json`) и сохранённый вход (`aurora-auth.json`).

### Про офлайн-профиль честно

| | Офлайн-профиль |
|---|---|
| Одиночная игра | работает полностью |
| Локальная сеть (LAN) | работает |
| Публичные серверы с проверкой лицензии | **не пустят** — подтвердить сессию нечем |
| Realms | **недоступны** |
| Скины и плащи | нет, их раздаёт Mojang по токену |
| Сама игра | скачивается с официальных серверов Mojang, как обычно |

Лаунчер не обходит защиту и не подделывает токены. UUID офлайн-игрока
считается по тому же алгоритму, что в самой игре
(`md5("OfflinePlayer:" + имя)`), поэтому мир не «меняет владельца», если
позже войти по-настоящему.

## Моды оптимизации — ровно 10

Список зафиксирован в манифесте, а не подбирается на лету: для каждого мода
там имя файла, размер, SHA-1 и SHA-512, поэтому установка воспроизводима.

Sodium · Lithium · ImmediatelyFast · Entity Culling · FerriteCore ·
BadOptimizations · ScalableLux · C2ME · Krypton · Dynamic FPS

**Fabric API** ставится одиннадцатым файлом, но в десятку не входит: это
библиотека-зависимость. Подробный разбор с версиями и датами —
[`aurora/docs/MODS.md`](aurora/docs/MODS.md).

Свериться с живым API Modrinth в любой момент:

```bash
python3 aurora/tools/verify_mods.py     # код возврата 1, если что-то разошлось
```

Iris и OptiFine не используются намеренно: Sodium работает без шейдерной
поддержки, а все эффекты AetherGlass рисуются обычным конвейером игры.

## Как выглядит

Один стиль на всё: меню игры, лаунчер и установщик.

- **Главное меню.** Тёмная зимняя ночь: холодный сине-фиолетовый градиент,
  ореол луны, снегопад, редкие стеклянные пластины. Поверх — галерея из
  четырёх фонов, которые медленно уходят в размытие и сменяют друг друга.
  Слева стеклянная пластина с названием и «чипами» сведений, справа док
  с кнопками: Одиночная игра, Сетевая игра, Realms, Настройки, Язык,
  Специальные возможности, HUD, Материалы, О клиенте, Выход.
- **Атмосферные надписи.** Одиннадцать фраз плавают по меню, медленно
  появляются и гаснут, слегка откликаются на курсор и не заходят на панели.
  Порядок берётся из «мешка»: пока круг не пройден, повторов нет. Настроек
  у них нет — ни включения, ни количества, ни прозрачности.
- **Стекло.** Спрайты считаются заранее инструментом
  `aurora/tools/make_menu_assets.py`: поле расстояний до формы даёт нормаль,
  у кромки фон выбирается со сдвигом вдоль нормали, и сдвиг разный для
  каналов RGB — это настоящее преломление, а не нарисованная рамка.
  В игре спрайт растягивается девятью частями, поэтому углы не плывут.

## Пересборка

Нужны JDK 21, Go 1.23 и кросс-binutils для цели `i686-w64-mingw32`.

```bash
cd aurora
bash tools/setup-launch4j.sh                       # кросс-компилятор launch4j (однократно)
./gradlew test :client:remapJar :launcher:exe :installer:exe dist
#   → dist/: AetherGlass.jar, AetherGlassLauncher.exe/.jar, AetherGlass-Setup.exe, CHECKSUMS.txt

cp client/build/libs/AetherGlass.jar launcher-go/core/assets/AetherGlass.jar
cd launcher-go && ./build.sh                       # → AetherGlass-Launcher.exe в корне
```

Память: в `gradle.properties` стоит `org.gradle.jvmargs=-Xmx900m`,
параллелизм выключен. Самая тяжёлая задача — `remapJar`.
Подробности, версии зависимостей и разбор частых ошибок —
[`aurora/docs/BUILD.md`](aurora/docs/BUILD.md).

## Проверено и не проверено

**Проверено по-настоящему:**

- `./gradlew test` — **116 Java-тестов, 0 провалов** (клиент 50, установщик 38,
  лаунчер 28) и **59 Go-тестов, 0 провалов**;
- `go vet ./...` — чисто и для Linux, и для `GOOS=windows GOARCH=amd64`;
- `:client:remapJar` — в собранном jar миксины содержат intermediary-имена
  (`class_310.method_1507`, `class_759.method_22976`, `class_9975.method_74926`),
  то есть ремап сделал Loom, а не «на доверии»;
- `scripts/check_pe.py` — все три `.exe` разбираются как настоящие PE-файлы
  с ресурсами, иконкой и сведениями о версии;
- `tools/verify_mods.py` — все 10 модов совпадают с живым API Modrinth;
- `MenuAssetTest` — каждая текстура, которую просит код, существует и имеет
  ровно тот размер, что объявлен в Java.

**Не проверено, и за работающее не выдаётся:**

- внешний вид меню и окна лаунчера — в сборочной среде нет ни Windows-сессии,
  ни видеокарты; Minecraft не запускался;
- работа ярлыков и записи в реестр Windows — сборка идёт на Linux;
- пиксельная обводка рук по силуэту — не реализована, причина разобрана в
  [`aurora/docs/LIMITATIONS.md`](aurora/docs/LIMITATIONS.md), раздел 7;
- смена аккаунта без перезапуска игры — лаунчер перезапускает игру с выбранным
  аккаунтом; in-game-переключателя в самом моде нет.

## Где что лежит

| Путь | Что |
|---|---|
| `aurora/client/` | мод: меню, эффекты, материалы |
| `aurora/launcher/` | лаунчер на Java → `AetherGlassLauncher.exe` |
| `aurora/installer/` | установщик → `AetherGlass-Setup.exe` |
| `aurora/launcher-go/` | нативный лаунчер одним файлом |
| `aurora/tools/` | генераторы ресурсов, проверка модов, тулчейн launch4j |
| `aurora/docs/` | `ARCHITECTURE.md`, `BUILD.md`, `FEATURES.md`, `MODS.md`, `RELEASE.md`, `AUDIT.md`, `LIMITATIONS.md`, `VERIFICATION_LOG.md` |
| `scripts/` | `privacy_audit.py` (личные данные и секреты), `check_pe.py` (настоящий ли PE) |

Исходники лежат в одном месте — `aurora/`. Прежняя копия в `workspace/aurora/`
удалена: две одинаковые ветки кода уже однажды разъехались, и правку пришлось
вносить дважды.
