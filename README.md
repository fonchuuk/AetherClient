# AetherGlass — что лежит в воркспейсе

Коротко, чтобы не искать. Всё, что нужно человеку с Windows, — один файл
**`AetherGlass-Launcher.exe`** в корне.

## Что есть

| Файл | Что это |
|---|---|
| `AetherGlass-Launcher.exe` | готовый лаунчер. Windows x64, один файл, Java для него не нужна |
| `AetherGlass.jar` | сам клиентский мод (меню, эффекты, материалы) — лаунчер кладёт его в игру сам |
| `aurora/` | исходники: `client/` — мод, `launcher-go/` — нативный лаунчер, `docs/` — вся документация |
| `README.md` | этот файл |
| `uploads/` | картинки-референсы, которые ты присылал |

## Как пользоваться

1. Запустить `AetherGlass-Launcher.exe`.
2. Вкладка «Аккаунт» → «Войти через Microsoft»: откроется браузер, пароль
   вводится на сайте Microsoft, лаунчер его не видит и не хранит.
3. Вкладка «Игра» → «Установить / обновить», потом «Играть».
4. Java ставить самому **не нужно**: лаунчер скачивает официальный рантайм
   Mojang (Java 21) в каталог игры. Если очень хочется свою — вкладка «Java».

Каталог игры по умолчанию: `C:\Users\<тебя>\.aetherglass`. Там же лежат
настройки (`aurora-launcher.json`) и сохранённый вход (`aurora-auth.json`).

## Как выглядит

Стиль один для всего: тёмное «жидкое стекло». За окном медленно плывут
размытые пятна, сверху — скруглённые стеклянные карточки со светлой кромкой,
кнопки-таблетки проминаются под нажатием пружиной, у статуса дышащая точка.
Слева — рельса вкладок (Аккаунт, Игра, Java, Настройки, Моды, Лог), справа —
страница.

Стекло рисует не наш код, а движок Chromium (WebView2 входит в Windows 10 и 11)
на видеокарте: размытие подложки даёт `backdrop-filter`, а преломление у кромки —
SVG `feDisplacementMap`, который физически сдвигает пиксели фона. Поэтому фон
может плыть непрерывно, а процессор отдыхает.

Своя Java для лаунчера **не нужна вообще** — это нативный exe. Java нужна
только игре, и лаунчер качает официальный рантайм Mojang сам.

## Что проверять в первую очередь

- окно открылось и не ругается на отсутствие Java (её и не должно быть нужно);
- вход через Microsoft доводит до имени игрока;
- установка доходит до «Игра установлена» и показывает, откуда взялась Java
  (ожидаемо: `своя Java (рантайм Mojang)`);
- после запуска игры — главное меню AetherGlass, а не ванильное.

Если что-то не так — вкладка «Лог»: там построчно видно, на каком шаге всё
остановилось.

## Пересборка

```bash
cd aurora/launcher-go && ./build.sh     # нужен Go 1.23, exe появится в корне
cd aurora && ./gradlew :client:remapJar # мод (нужен JDK 21)
```

## Честные ограничения

- Вид окна лаунчера ни разу не проверен глазами: в сборочной песочнице нет
  Windows. Проверены код (`go vet`, 29 тестов, `go test -race`), сборка и
  живой прогон установки — но не картинка.
- Клиентский мод вшит в exe. Если править мод, exe нужно пересобрать.
- Первый запуск требует интернет: игра, моды и Java качаются один раз.

Текущая сборка: **8 548 864 байта**,
sha256 `11990cb4f95deb643a807a0f0c9d32bbec28e2c2d0f34d1c42df7dec496075ff`.

## Как закинуть на GitHub

Репозиторий уже инициализирован и первый коммит сделан, поэтому после
распаковки достаточно привязать свой репозиторий и отправить:

```bash
git remote add origin https://github.com/<твой-логин>/<репозиторий>.git
git branch -M main
git push -u origin main
```

Автора коммита стоит поменять на себя — сейчас там служебный:

```bash
git config user.name  "Твоё Имя"
git config user.email "твоя@почта"
git commit --amend --reset-author --no-edit
git push -f origin main
```

Если распаковщик выкинул `.git`, инициализируй заново: `git init && git add -A && git commit -m "AetherGlass"`.

Что уже учтено:

- `.gitignore` — тулчейны сборки, `build/`, `.gradle/`, `*.class`, `*.syso`;
- `.gitattributes` — у `*.sh` и `gradlew` жёстко LF, у `*.bat` — CRLF, двоичные
  файлы помечены `binary`. Без этого `gradlew` и `build.sh` на Windows ломаются;
- готовый `AetherGlass-Launcher.exe` **не** исключён: он и есть главный файл.

## Что лежит в `aurora/` и что оттуда можно выкинуть

| Каталог | Нужен? |
|---|---|
| `aurora/client/` | да, исходники мода |
| `aurora/launcher-go/core/` | да, вся логика лаунчера |
| `aurora/launcher-go/uiweb/` | да, окно и страница интерфейса |
| `aurora/launcher-go/ui/` | нет — старый интерфейс на Win32, нигде не подключён. Оставлен запасным |
| `aurora/launcher/` | нет — самый первый лаунчер на Java, от которого отказались |
| `aurora/installer/` | нет — установщик, ты просил только сам лаунчер |
| `aurora/docs/`, `aurora/assets/` | да |
